New release of Costa - version 1.3.0

Posted October 22nd, 2020

After a 2½ year hiatus, I have once again pulled the source code for Costa out of storage, and added some new features. This time around, I’ve implemented some bug fixes, and a whole new theme editor.

With this new theme editor, users can now customize any color of the interface - either by modifying existing themes, or making their own. User submissions are welcome!

New release of Costa - version 1.2.0

Posted May 27th, 2018

Once again I have released a new version Costa, version 1.2.0.

The main feature in this new version is support for multiple profiles. It is now possible for several users to use the same installation of Costa, each with their own settings, theme and personal desktop. One user could also have separate profiles for work, play etc.

Full changelog for this and previous releases are available in the archive.
